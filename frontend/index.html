Modo explicação

A VHX Dupla aplica duas Vigenères com chaves diferentes e, no meio, inverte blocos de 3 letras. A 1ª chave é SOL; a 2ª deriva dela: TPM.

Entrada

1ª chave: SOL (alterna com LOS)

2ª chave: TPM (SOL avançada 1 posição; alterna com MPT)

Vigenère: C = (P + K) mod 26

A = 0, B = 1, …, Z = 25

Ordem das operações

  1. Texto
  2. Vigenère 1 com SOL / LOS
  3. Dividir em blocos de 3
  4. Inverter cada bloco
  5. Vigenère 2 com TPM / MPT
  6. Texto cifrado

O que a VHX Dupla junta

Vigenère 1

  • A chave fixa SOL se alterna com LOS a cada 3 letras.
  • Cada letra soma o valor da letra da chave, módulo 26.
  • Exemplo: ATAQUE usa a chave SOLLOS.

Inversão de blocos

  • O texto da 1ª Vigenère é cortado em blocos de 3 letras.
  • Cada bloco é escrito de trás para frente.
  • Muda a ordem das letras, sem mudar o valor delas.

Vigenère 2

  • A 2ª chave deriva da 1ª: cada letra avança 1 posição (SOL → TPM).
  • TPM se alterna com MPT a cada 3 letras.
  • Quem tentar só a Vigenère clássica não recupera a palavra original.
