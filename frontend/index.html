Modo explicação

A VHX parte da Cifra de Vigenère e acrescenta duas regras: a chave de três letras alterna entre a forma normal e a invertida a cada bloco, e cada bloco é invertido depois do cálculo.

Entrada

Criptografia: C = (P + K) mod 26

Descriptografia: P = (C - K) mod 26

A = 0, B = 1, …, Z = 25

Ordem das operações

  1. Normalizar o texto para A–Z
  2. Dividir em blocos de 3 letras
  3. Aplicar Vigenère com chave normal ou invertida
  4. Inverter as letras de cada bloco
  5. Unir os blocos no texto cifrado

Vigenère tradicional e VHX

Vigenère tradicional

  • A chave se repete sempre na mesma ordem.
  • As letras permanecem na mesma posição.
  • Exemplo: AGTAGTAG…

VHX

  • A chave alterna entre normal e invertida a cada bloco.
  • O resultado de cada bloco é invertido.
  • Exemplo: AGT | TGA | AGT | TGA

A VHX foi feita para demonstração em sala. Para proteger dados reais, use algoritmos modernos, como AES.
